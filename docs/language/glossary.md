# 用語集（ユビキタス言語）

以降の段（BDD のシナリオ、DDD の型、コードの名前）は、ここにある言葉だけを使う。
ここに無い言葉が出てきたら、ここに足してから使う。

| 用語 | 意味 | 備考 |
|---|---|---|
| **計画**(Plan) | 運転者が作る、1台の車の送迎の計画全体 | 集約の候補 |
| **運転者**(Driver) | 計画を作り、出発地・目的地・到着希望時刻を決める人 | |
| **同乗者**(Passenger) | 運転者の車に乗る人。自分の拾ってもらう地点を入れる | |
| **出発地**(Origin) | 運転者が最初に出発する地点 | |
| **目的地**(Destination) | 最終的に向かう地点。v1 ではゴルフ場 | 「ゴルフ場」と呼ばない |
| **拾ってもらう地点**(PickupPoint) | 同乗者ごとの、乗る場所 | 「経由地」も同じ意味で使うことがある |
| **到着希望時刻**(DesiredArrivalTime) | 運転者が目的地に着きたい時刻 | 計画の起点。ここから逆算する |
| **出発時刻**(DepartureTime) | 到着希望時刻から逆算して出る、各地点の出発時刻 | 地点ごとに出る |
| **お迎えの順番**(PickupOrder) | 拾ってもらう地点を回る順番。アプリが自動で決める | 運転者は並べ替えない |
| **積み込み時間**(BoardingDuration) | 各地点で人を乗せるのにかかる時間。固定値 | v1 では全員・全地点で同じ |
| **共有リンク**(ShareLink) | 同乗者が計画を見る・地点を追加するための URL | 権限の扱いは Hotspot |
| **再計算**(Recalculation) | 出発地・経由地・目的地が変わったときに、お迎えの順番と時刻を出し直すこと | 地点が変わらない限りしない |
| **予定**(Schedule) | v1 では「送迎の計画」と同じ意味。将来ゴルフ以外にも使う前提でこの言葉を使う | 「ラウンド」と呼ばない |

## 使わないと決めた言葉

| 言葉 | 代わりに使う言葉 | 理由 |
|---|---|---|
| ラウンド | 予定 | ゴルフ固有にしない（00-why.md 非機能要件） |
| ゴルフ場 | 目的地 | 同上 |
| 経由地の構成 | 拾ってもらう地点の集まり | 「構成」は曖昧。地点そのものを主語にする |
